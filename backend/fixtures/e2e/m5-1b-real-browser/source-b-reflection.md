# Source B｜关于“一个人吃饭”的误会

我以前把独处和被剩下混在一起。关系结束后的那段时间，只要看到餐厅里只有自己一套餐具，就会觉得那是一张成绩单，证明别人都回到了某段关系里，只有我没有。这个联想并不完全来自分手。小时候家里常说“一个人就随便吃点”，好像认真做饭必须有另一个人在场才值得。

搬来杭州前，我甚至买了最小号的电饭煲，理由是一个人不需要太大的。真正开始使用后才发现，它一次煮出来的饭还是够吃三顿。我第一次把剩饭分装冷冻时有点好笑：原来为未来两天的自己留饭，也算是在照顾一个具体的人，不需要等客人出现。

我妈每次视频都会问吃了没有。我一开始总把镜头对着做好的菜，像在交作业。有天我只吃了速冻水饺，没有拍照，直接说今天很累，不想做。她沉默两秒，说那你记得把冰箱里的水果吃掉。那次之后，我慢慢停止用一张漂亮的晚饭照片证明自己过得很好。

一个人吃饭最难的不是安静，而是没有人替这一天收尾。两个人吃饭时，哪怕只说一句“这个有点咸”，一天也像被共同确认过。独居以后，我会在饭桌旁放播客，最初是为了盖住冰箱启动的声音。后来有几次节目播完了，我没有立刻找下一集，只听见楼下电动车倒车和水壶沸腾。安静没有变得浪漫，只是没有以前那么像惩罚。

我也试过把独居包装成一种很漂亮的生活方式：买花、点蜡烛、给每顿饭摆盘。坚持不到一周就放弃了，因为周三加班回家，我根本不想擦烛油。现在餐桌上常有没拆的快递和电脑线。有时我把它们推到一边吃饭，有时干脆端着碗站在厨房。对我来说，接受这种不体面比制造氛围更接近真正的放松。

真正让我改变的不是某顿特别成功的晚餐，而是重复。菜市场阿姨知道我买半把葱；楼下便利店的店员提醒饭团第二件半价；邻居偶尔送来一小碗馄饨；我开始记得周三垃圾分类车几点来。这些关系都很浅，但它们让一个人生活不再等于和世界断开。

我仍然会在某些周末晚上感到孤单。朋友聚会结束以后回到家，玄关没有第二双鞋，这个事实不会因为我学会做饭就消失。我现在能做的是不急着把这种感觉解释成“我选错了城市”或“我不值得被爱”。有时它只说明今天很想有人陪。承认这一点，然后给朋友发消息，或者早点睡，都比给自己讲一套独立女性的道理有用。

如果这期节目要留下一句话，我希望不是“要学会享受孤独”。我没有一直享受，也不想把独处变成新的考试。更准确的说法也许是：我终于愿意在没有观众的时候，把一顿普通晚饭做给自己吃。

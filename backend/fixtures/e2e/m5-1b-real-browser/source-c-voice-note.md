# Source C｜一次口述补充：那顿焦掉的番茄炒蛋

我再讲具体一点。那天大概七点半到家，外套肩膀是湿的。我开门以后没有马上换鞋，先站在玄关看了一眼厨房。其实我完全可以点外卖，但那两个番茄已经放了快一个星期，表皮有一点皱。我当时想，再不吃就只能扔了。

我以前看前任做过很多次番茄炒蛋，所以错误地觉得自己也会。鸡蛋下锅以后我才发现油太少，铲子又在还没拆的箱子里。我拿了一把木勺去翻，底下已经粘住。烟没有大到触发报警器，只是有一股很明显的焦味。我把窗户推开，雨水马上飘进来，又赶紧关上。

最想点外卖的时刻不是发现鸡蛋焦了，是我把番茄倒进去以后，锅里一下出了很多水。我觉得这顿饭已经没有挽救的可能，就站在那里看了十几秒。后来我加了一点盐，把火关了。不是因为突然有什么意志力，只是外卖页面上的配送时间要四十五分钟，而我已经很饿。

餐桌那时还没装好。我把两个纸箱并在一起，上面垫着一本杂志，蓝边碗放上去会有点晃。我吃第一口的时候觉得又酸又咸，鸡蛋边缘确实苦。我还是慢慢吃完了，中间给朋友拍过一张照片，但最后没有发。我不想听见“你好惨”或者“终于会做饭了”这种评价，那顿饭当时还没有任何意义。

吃完我洗锅洗了很久。粘住的鸡蛋要先泡水，我就在旁边拆装着餐具的箱子。找到那把正常的锅铲时我真的笑了，因为如果早十分钟找到，可能整顿饭会好一点。那晚我把锅铲挂在灶台旁边，也把盐从塑料袋倒进一个玻璃罐。第二天早上看到它们在那里，厨房才第一次不像短租房。

后来我为什么没点外卖，我觉得不用解释成坚强。更像是我第一次没有马上逃离一个不够好的结果。以前只要计划失败，我就会换一家餐厅、换一个安排，或者找人陪我。那天我吃完了，而且第二周又做了一次。这两次之间没有顿悟，只有我记得多放一点油、番茄晚一点下锅。

还有一个细节是那只蓝边碗。它本来是一对，另一只在搬家时裂了。我一直舍不得扔掉剩下这只，又觉得一只碗摆在柜子里很难看。现在它是我用得最多的一只。这里很容易写得象征化，但我真的不觉得它代表什么完整或残缺。主要是它大小合适，而且洗起来方便。

如果要把这段讲给第一次独居的人听，我不会说一个人做饭就能治愈分手。分手还是会在一些具体时刻回来，比如切菜时听到以前一起听的歌，或者下意识做了两人份。我只想把那顿很难吃的饭留在节目里，因为它让我知道，生活可以从一个不漂亮、甚至有点焦的版本开始。

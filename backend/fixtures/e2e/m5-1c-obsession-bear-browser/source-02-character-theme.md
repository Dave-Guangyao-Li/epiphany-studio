# Source 02｜Bear、Nikki 与电影主题（主创解释层）

> 本文件区分主创明确表达和我们据此提出的写作方向。后者用于创作实验，不等于唯一正确的电影解读。

导演 Curry Barker 说，他想把熟悉的许愿故事放进现实反应里，让一个普通人在极端处境中的选择保持自然和不舒服。Bear 不是一个可以简单归类的“好人”。他有脆弱、孤独和尴尬，也有自我中心、逃避与残忍。导演不想替观众决定应该同情还是谴责，而是希望观众离场后仍争论：在两个选项都很糟的处境里，什么才是正确的选择。

饰演 Bear 的 Michael Johnston 把人物的核心理解为：Bear 相信只要得到 Nikki，人生就会变好，于是没有先面对自己的空洞。他的自我价值依赖外界认可，缺少处理拒绝和孤独的能力。这个解释使“许愿”不只是一次偶然错误。更重要的分界在愿望已经显效以后——当 Bear 看见 Nikki 的主体性正在消失，却仍愿意享受她给予的爱，他从半信半疑进入了知情的自我欺骗。

Nikki 在愿望发生前的感情必须保持未知。相关采访指出，故事采用 Bear 的视角，开场的 Nikki 也经过他的投射；演员的理解则保留了她可能有一点兴趣、也可能只把 Bear 当朋友的两种读法。导演谈到两位演员缺少恋爱化学反应，认为这正符合故事；这些不同表述不能被改写成“Nikki 原本一定不会爱他”，同样不能写成“如果 Bear 勇敢告白就一定会成功”。她的拒绝权本身，比拒绝的结果更重要。

Inde Navarrette 和主创把 Nikki 的恐怖核心指向主体性与身体自主权的丧失。愿望后的爱没有保留一个可以改变主意、说不、离开或把其他人放在 Bear 前面的 Nikki。她偶尔清醒时的恐惧，说明 Bear 梦想中的“被绝对选择”与一个真实的人不能共存。电影也故意遮蔽 Nikki 的脸，让观众无法判断下一秒是亲吻还是伤害，把亲密和危险放进同一个不稳定空间。

用于本次第一人称写作的核心不是让 Bear 直接背诵 consent、projection 或 nice-guy entitlement 等概念。更有效的方式是让他在具体瞬间露出裂缝：他为什么愿意忽略第一次清醒；为什么听见求救后仍问“和我在一起有什么不好”；为什么补救时仍然拒绝最痛苦的选择；为什么吞药后又立刻后悔。这样才能保留导演所说的灰度，而不是给 Bear 安排一条干净的英雄救赎线。

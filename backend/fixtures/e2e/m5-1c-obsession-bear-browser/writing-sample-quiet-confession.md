# Writing Sample｜凌晨两点，我把杯子洗了三遍

> 【只用于表达风格】这是完全原创、与电影剧情无关的合成样本。它提供迟疑、自我纠正、具体物件和不强行总结的口吻，不能作为 Bear 或 Nikki 的事实来源。

我把那只杯子洗了三遍。第一次是正常洗，第二次因为闻到一点咖啡味，第三次其实已经没有理由。我站在水槽前，把海绵捏到不再出泡沫，还是不想关水。

那天我刚对一个人撒了谎。严格说也不算一句完整的谎，我只是漏掉了最重要的半句。别人问我是不是早就知道，我说没有。我确实没有“早就”知道，只提前了四十分钟。人很擅长把时间副词拿来当道德逃生门。

杯口有一道很浅的裂纹，指甲划过去会停一下。我以前总觉得裂掉的杯子应该扔，可它没有漏水，拿起来也顺手。这个细节很容易被写成象征，我当时没想那么多。我只是不想回到客厅，因为手机放在那里，屏幕上还有一句没有回复的话。

水一直开着让我显得很忙。洗杯子是一件不会出错的事：有污渍就擦，有泡沫就冲，最后把它倒扣在架子上。可那句漏掉的半句话没有对应步骤。我如果现在补上，会显得前面的沉默经过计算；如果继续不说，又可以假装事情已经过去。

最后是楼上的人敲了一下暖气管，我才把水关掉。厨房忽然很安静，杯子里残留的一滴水顺着内壁滑下来。我没有得到勇气，只是手已经没有别的事情可做。我回到客厅，把那半句发了出去。

对方没有立刻回复。三分钟后也没有。以前的我可能会说，至少我终于诚实了，好像诚实是按下发送键就完成的一件事。那晚我更清楚的是，补说并不会取消之前的隐瞒。它只是让另一个人终于拿到完整信息，接下来怎么判断，不再由我安排。

第二天早上，杯子还倒扣在架子上。我拿它喝水，裂纹也还在。事情没有因为一个夜晚得到漂亮结局。我只少了一个可以继续装作不知道的借口。
